2) LỖI 2 — Hướng (a) AbortController khi rời tab ETL giữa chừng
========================================================================
Case A (rời tab ETL trước 800ms, trước khi 15 request ETL kịp bắn):
  javascript_exec ngay sau navigate:
    window.__caseA = {clickAt: performance.now()};
    document.getElementById('place-tab-btn').click();
    etlTabLoadedRightAfter = false
  Sau 10s: performance entries cho thấy etlQueueFired = 0/12 (KHÔNG request namevi-queue nào
  được bắn), vi-map GET /daoanh/api/places/vi-map?page=1&size=50&filter=all → 200 OK,
  dur ~1.7s (lượt đo ổn định) hoặc tới ~17.9s (lượt đo trùng lúc server đang xử lý câu
  LIKE chưa có index idx_namevi_places_dila_id — vấn đề lỗi 1, NGOÀI phạm vi phiên này).
  → Kết luận: tab Place không bị 15 request ETL cạnh tranh pool nữa khi Admin rời tab sớm.
