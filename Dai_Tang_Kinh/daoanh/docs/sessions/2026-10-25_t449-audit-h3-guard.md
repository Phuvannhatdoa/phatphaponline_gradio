## 7. Sai lầm / bài học

- `git checkout HEAD -- <path>` với đường dẫn tính từ repo root **fail** khi `cwd` là
  `daoanh` (`pathspec did not match`) → pathspec của `checkout`/`add` là **tương đối cwd**.
- PowerShell không có heredoc `<<'PY'` → luôn ghi temp `.py` vào `%TEMP%` rồi chạy.
- `Get-ChildItem | Sort-Object` trong pipeline lỗi "Cannot run a document in the middle of a
  pipeline" (Get-ChildItem bị shadow) → dùng `python -c "glob..."`.
- Chẩn đoán "script ghi đè" phải so **HEAD vs worktree** (`git diff --stat HEAD -- <path>`),
  không chỉ nhìn file: file 57 B có thể do lần chạy trước, không phải lần mình vừa chạy.
- ⚠️ **TỰ GÂY RA:** script merge của tôi mở `docs/tasktodo.md` bằng `"w"` **trước khi** tính nội
  dung → truncate về 0 byte (đúng lỗi mà T449 đang sửa!). Đã khôi phục từ blob HEAD + block T449;
  **mất 3 dòng WIP chưa commit của session T462** trong `docs/tasktodo.md` (không tìm thấy bản
  nào khác: index = HEAD, VSS/VS Code backup/temp index đều không có). Bài học: luôn tính nội dung
  trước, ghi qua `<file>.tmp` + `os.replace`; file do `git checkout` tạo có thể không cho
  `os.replace` (WinError 5) → fallback `open(path,"r+b")` + `truncate()` sau khi backup.
