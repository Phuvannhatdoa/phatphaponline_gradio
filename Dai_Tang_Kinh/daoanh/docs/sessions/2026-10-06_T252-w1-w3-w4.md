## 4. Ghi chú kỹ thuật phát hiện trong phiên

  viết chữ Hán **literal** (file UTF-8), đừng escape tay. Thêm: JSON của tool
  edit **nuốt** `\uXXXX` → `oldString`/`newString` thành chữ thật, không match
  được chuỗi escape trong file → phải sửa bằng Python (`str.replace`).
