### 2. Admin 404 fix (admin/index.html + admin/dila_person_index.html)

**Vấn đề:** Links trong `admin/index.html` bị 404:
```html
<a href="dila_index.html">DILA Place Index</a>        <!-- relative → sai -->
<a href="dila_person_index.html">DILA Person Index</a>
```
Khi served tại `/daoanh/admin` (không có trailing slash), trình duyệt resolve
relative path thành `/daoanh/dila_index.html` (sai — 404).

**Fix — admin/index.html** (lines 431, 438):
```html
<a href="/daoanh/admin/dila_index.html">DILA Place Index</a>
<a href="/daoanh/admin/dila_person_index.html">DILA Person Index</a>
```

**Fix — admin/dila_person_index.html** (line 51):
