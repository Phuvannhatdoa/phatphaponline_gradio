## Những gì đã làm

### Fix bug: Route /related 404

**Root cause 1**: Server cũ (debug=False, không auto-reload) đang chạy code cũ
— route `GET /daoanh/api/entity/<entity_id>/related` đã được thêm vào `app.py`
nhưng server chưa restart.

**Root cause 2**: Nhiều server Python (PID 5344, 19796, 20128) chạy đồng thời
trên port 5000 (do restart không kill đủ). Server đang phục vụ request là process
cũ không có route mới.

**Root cause 3**: Sau khi restart đúng server, còn 2 lỗi DB:
- `people` table không có cột `dila_id` — query canonical persons dùng
  `WHERE dila_id = ?` sai. Fix: `WHERE id = ?` (people.id = "A000001" format).
- `cbeta_text_catalog` và `entity_text_map` chưa tồn tại trong DB. Fix: wrap
  query texts trong try/except, trả `texts=[]` nếu lỗi.
