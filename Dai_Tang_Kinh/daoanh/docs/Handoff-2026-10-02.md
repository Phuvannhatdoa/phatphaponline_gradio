## 2. Cảnh báo bắt buộc trước khi làm gì

### 🔴 C1 — `git index.lock` bị khoá, index thật đang STALE

**Hiện trạng:** `.git/index.lock` (0 byte, tạo 12:02:36) bị giữ bởi tiến trình
hệ thống. **Không xoá được, không đổi tên được** → `Access denied`.
Không có `git` process nào chạy, nhưng OS không cho gỡ.

**Hệ quả:** `git add` / `git commit` / `git read-tree` trên **index thật** đều
thất bại. Và index thật **vẫn giữ nội dung Cũ** của 24 file đã commit trong phiên
này (do commit đi qua index tạm) ⇒ `git diff --cached` in ra **24 file là rác**.

> **TUYỆT ĐỐI KHÔNG chạy `git commit` không có tham số path** — git sẽ commit 24
> file đó và **xoá ngược công việc T208–T211**.

**Cách commit an toàn** (đã dùng cả phiên này — xem `tasks/G208-safe-commit-revert-procedure.md`):
```bash
export GIT_INDEX_FILE="$PWD/.git/wt_tmp_index"
git read-tree HEAD              # index tạm, baseline ĐÚNG — KHÔNG cp .git/index
git add -- <đúng những file cần commit>
git diff --cached --name-only   # BẮT BUỘC kiểm trước khi commit
# nếu git commit vẫn lỗi (do index.lock) → plumbing:
TREE=$(git write-tree)
NEW=$(git commit-tree "$TREE" -p HEAD -F /path/to/msg.txt)
git update-ref refs/heads/master "$NEW" HEAD
unset GIT_INDEX_FILE
```

**Dọn index thật** (khi nào khoá được gỡ):
```bash
rm -f .git/index.lock
git read-tree HEAD
git status --short          # phải không còn 24 file staged
```
