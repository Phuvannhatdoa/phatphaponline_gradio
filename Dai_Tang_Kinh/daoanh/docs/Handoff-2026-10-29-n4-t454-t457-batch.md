## 4. Cảnh báo bắt buộc

> ⚠️ **Mọi mục dưới đây đều dễ bị sót — đọc kỹ trước khi làm việc mới.**

### 4.1 Git trên máy này KHÔNG dùng `git add` / `git checkout`
- **`git add` cây thư mục** → nuốt WIP của session khác. Chỉ dùng **blob + `update-index --cacheinfo` + `commit-tree` + CAS ghi ref trực tiếp** (xem `scripts/commit_tasks.py`).
- **`git checkout -- <file>`** → **xoá mất** thay đổi chưa commit của session khác (đã xảy ra: `git checkout --` fail với *"fatal: unable to write new index file"* → **đã revert nhầm 2 task file**, phải restore lại từ HEAD blob).
- **`git revert --no-commit`** → **GHI VÀO WORKTREE**. Script verify của mình đã xoá nhầm 24 file → phải restore. Dùng `git apply --check --cached --reverse` hoặc **worktree cô lập** (`git worktree add --detach <tmp> HEAD`) để verify, **không** chạy revert trong worktree chính.
- **PowerShell `>` redirect** → ghi file **UTF-16LE** → git coi là **binary** → `git revert` / `git apply` fail. Luôn dùng `python -X utf8 script.py > out.txt` hoặc `| Out-File -Encoding utf8`.
- **`git update-ref`** CAS fail (`WinError 5` khi `os.replace`) → ghi file ref trực tiếp, tự kiểm CAS bằng tay.

### 4.2 `docs/tasktodo.md` và `docs/ROLLBACK.md` — file dùng chung

- Quy tắc: dựng blob từ **index** (`git ls-files -s` → `git cat-file blob <sha>`), **không** lấy worktree → không nuốt WIP của họ.
- `git status` trên máy này **hỏng im lặng** (exit 1, stdout/stderr 0 byte) khi không có pathspec → dùng `git diff --cached` / `git diff <a> <b>`.
